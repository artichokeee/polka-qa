# Чек-лист оформления заказа

- [ ] Товар добавляется в корзину, счетчик на иконке растет
- [ ] Удаление товара из корзины уменьшает сумму
- [ ] Адрес доставки сохраняется
- [ ] Сумма к оплате совпадает с суммой корзины плюс доставка
- [ ] После оплаты заказ виден в "Моих заказах"
- [ ] Купон применяется, скидка видна в сумме
- [ ] Просроченный купон дает понятную ошибку
- [ ] Счетчик корзины после удаления товара
- [ ] Валюта в ответе API – RUB
