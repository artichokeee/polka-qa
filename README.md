# Полка – интернет-магазин

Учебный репозиторий курса "Рабочий день тестировщика: Git и терминал". Код магазина упрощен: он нужен,
чтобы читать историю, ветки и изменения, а не чтобы запускать сайт.

## Что где

- `src/` – код магазина: корзина, купоны, оплата, каталог, API
- `config/` – настройки стенда и прода, настройки оплаты
- `data/` – тестовые данные: товары, купоны, тарифы доставки
- `qa/` – чек-листы и тестовые заказы
- `docs/release-notes.md` – что вошло в релизы
- `logs/` – журнал вечера и ночи после релиза 3.8

## Проверка суммы заказа

```
bash check.sh
```

Код выхода: 0 – сумма заказа 1042 уходит в шлюз верно, 1 – неверно, 125 – проверить нечем.
